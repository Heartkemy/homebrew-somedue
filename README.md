# Somedue for Homebrew

A maintainer-owned tap for Somedue's local-only macOS previews.

```sh
brew install --cask heartkemy/somedue/somedue
```

For downloads, checksums, source and contribution instructions, see [Somedue](https://github.com/Heartkemy/somedue).

These previews are ad-hoc signed and not notarized. Homebrew retains quarantine; macOS may block opening the app. This tap does not disable or bypass macOS protections. Downloads cannot connect to Things Cloud.
